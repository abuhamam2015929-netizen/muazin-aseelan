# مؤذن عسيلان

تطبيق أندرويد إسلامي (Kotlin) لعرض مواقيت الصلاة والأذان لمنطقة **عسيلان** في القصيم، يعمل بالكامل دون اتصال بالإنترنت.

## المزايا
- جدول مواقيت كامل لـ 12 شهراً مدمج داخل التطبيق (بدون إنترنت).
- تنبيهات وأذان يعمل في الخلفية حتى مع إغلاق التطبيق (AlarmManager + Foreground Service).
- 6 مؤذنين يمكن اختيار الصوت المفضل لكل صلاة على حدة (الملفات الصوتية تُضاف لاحقاً في `app/src/main/res/raw/`).
- أوضاع تنبيه لكل صلاة: أذان كامل / تنبيه قصير / صامت / إيقاف.
- تذكير مسبق قابل للتخصيص (5 / 10 / 15 دقيقة).
- تعديل يدوي لدقائق كل صلاة، وتعديل يدوي للتاريخ الهجري.
- بوصلة قبلة تعمل بمستشعرات الجهاز الفعلية.
- تصميم بألوان أخضر زيتوني / ذهبي / بيج مطابق للهوية البصرية.

## قبل البناء
1. ضع ملفات الأذان الصوتية (MP3) في `app/src/main/res/raw/` بالأسماء الموضحة داخل نفس المجلد.
2. عدّل إحداثيات عسيلان الدقيقة في `QiblaFragment.kt` (الثوابت `ASEELAN_LAT` و`ASEELAN_LON`) إذا رغبت بدقة أعلى للبوصلة.

## البناء عبر GitHub Actions (بدون حاسوب)
عند رفع المشروع إلى GitHub، سيقوم سير العمل الموجود في
`.github/workflows/build-apk.yml` تلقائياً ببناء ملف APK عند كل Push إلى فرع `main`،
ويمكن تحميل الناتج من تبويب **Actions** داخل صفحة الـ Artifacts.

يمكن أيضاً تشغيله يدوياً من تبويب Actions عبر زر **Run workflow**.

## هيكل المشروع
```
app/src/main/java/com/aseelan/adhan/
├── data/          نماذج البيانات وجدول المواقيت والإعدادات
├── alarm/         جدولة وتشغيل الأذان في الخلفية
├── ui/home/       الشاشة الرئيسية
├── ui/qibla/      بوصلة القبلة
├── ui/settings/   الإعدادات
└── util/          أدوات مساعدة (الإشعارات)
```
